# KAUPC2026 참가자 포털 통합 설계

## 목표

개인전 참가자가 보는 모든 경로에서 `team` 용어와 URL을 제거한다. 외부 주소는 `/contest`로 통일하고, 문제·제출·순위표·질의응답을 같은 레이아웃 규칙으로 보인다.

## 경로

DOMjudge 코어의 `/team` 라우트는 수정하지 않는다. Caddy가 외부 `/contest` 요청을 내부 `/team` 요청으로 변환한다. DOMjudge가 보내는 `/team` 리디렉션과 기존 `/team` 북마크는 `/contest`로 되돌린다. 로그인 뒤에는 `/contest` 대회 선택 로비가 열린다.

## 공통 화면 규칙

- 로비를 제외한 대회 내부 페이지는 대회명을 제목이나 부제에 반복하지 않는다.
- 본문은 최대 980px, 좌우 24px 여백의 공통 셸을 사용한다.
- `문제`, `제출`, `순위표`, `질의응답` 탭은 같은 위치와 스타일을 사용한다.
- 각 페이지 제목은 기능명만 쓴다. 필요한 설명은 한 줄의 보조 문구로 둔다.
- 기본 콘텐츠는 동일한 테두리·반경·여백의 패널로 묶는다. 제출 필드만 패널 안에서 최대 560px로 제한한다.
- 순위표는 공통 셸을 유지하며 좁은 화면에서 수평 스크롤한다.
- 질의응답은 공통 셸과 탭 아래에 공지·문의 카드 목록으로 표시한다.

## 제출 상세 번역

제출 상세의 영문 라벨과 컴파일 결과 문구를 한국어로 치환한다. 문제명·제출 시각·언어·결과는 같은 요약 패널에 표시하고, 컴파일 결과는 별도 상태 문구로 표시한다.

## 검증

정적 테스트는 참가자 스크립트가 `/contest`만 생성하고, `/team` 자동 리디렉션과 대회명 반복을 만들지 않음을 검사한다. Caddy 설정은 `/contest` 프록시와 레거시 `/team` 리디렉션을 검사한다. 실제 브라우저에서는 로그인, 대회 선택, 문제, 제출, 순위표, 질의응답, 제출 상세를 확인한다.
