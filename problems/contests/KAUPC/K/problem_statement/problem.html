문제

두 고양이 랑이와 메리는 매일 주어지는 간식 중 맛있는 것을 자신이 먹기 위해 경쟁한다.

랑이와 메리가 사는 집은 N × M 크기의 직사각형으로 표현할 수 있다. 해당 직사각형의 위에서부터 x번째, 왼쪽에서부터 y번째 위치를 (x, y)라고 표현한다. 매일 (x, y) 위치에는 A[x][y]만큼의 맛을 가진 간식이 주어진다. 값이 큰 것이 맛있는 간식이다.

아래 그림은 5 × 6 크기의 직사각형으로 표현되는 집에 간식이 채워진 예시로, A[1][1] = 6이고 A[5][6] = 5인 상황이다.

랑이와 메리는 매일 간식이 채워지면 다음과 같은 과정을 통해 간식을 나눠먹는다.

1. 랑이가 네 정수 x1, y1, x2, y2을 정해서 왼쪽 위 좌표가 (x1, y1)이고 오른쪽 아래 좌표가 (x2, y2)인 직사각형 구간에 있는 간식을 전부 먹는다.

2. 랑이가 다시 한 번 네 정수 x3, y3, x4, y4를 정해서 왼쪽 위 좌표가 (x3, y3)이고 오른쪽 아래 좌표가 (x4, y4)인 직사각형 구간에 있는 간식을 전부 먹는다.

3. 메리가 남은 간식 중 하나를 먹는다.

4. 나머지 모든 간식을 랑이가 먹는다.

간식을 단 하나밖에 먹지 못하는 것이 억울한 메리는 자신이 먹을 수 있는 간식 중 가장 맛있는 간식을 먹는다.

아래 그림은 x1 = 2, y1 = 1, x2 = 5, y2 = 3인 상황이다. 녹색으로 칠해진 구간에 있는 간식을 랑이가 모두 먹는다.

그 후 랑이가 다시 x3 = 3, y3 = 5, x4 = 4, y4 = 6 구간을 먹는다면 랑이가 간식을 먹은 위치는 다음과 같이 표현된다.

그 이후 메리는 남은 간식 중 가장 맛있는 간식 하나를 먹는다. 그림에서는 A[1][1] = 6을 먹게 된다. 동일한 값으로 A[3][4] = 6이나 A[5][5] = 6을 먹을 수도 있다.

만약 랑이가 (1, 1)부터 (5, 3)까지의 간식을 먹은 뒤 (3, 4)부터 (5, 6)까지의 간식을 먹는다면 메리는 A[1][4] = 5 또는 A[2][5] = 5를 먹게 된다.

Q일 동안의 x1, y1, x2, y2, x3, y3, x4, y4가 주어진다. 각 날짜에 메리가 먹게 되는 간식의 맛을 출력하는 프로그램을 작성하시오.

입력

첫 줄에 두 정수 N, M이 공백으로 구분되어 주어진다.

둘째 줄부터 N줄에 걸쳐 간식의 정보가 주어진다. 한 줄에 M개의 정수가 공백으로 구분되어 주어지며, 이 중 x번째 줄의 y번째 값은 A[x][y]를 의미한다.

N + 2번째 줄에 정수 Q가 주어진다.

N + 3번째 줄부터 Q줄에 걸쳐 각 날짜의 x1, y1, x2, y2, x3, y3, x4, y4가 공백으로 구분되어 주어진다.

출력

Q줄에 걸쳐 각 날짜에 메리가 먹을 수 있는 가장 맛있는 간식의 맛을 한 줄에 하나씩 출력한다.

제한

  • 2 ≤ N ≤ 1,000
  • 2 ≤ M ≤ 1,000
  • 1 ≤ A[x][y] ≤ 1,000,000
  • 1 ≤ Q ≤ 100,000
  • 1 ≤ x1 ≤ x2 ≤ N
  • 1 ≤ x3 ≤ x4 ≤ N
  • 1 ≤ y1 ≤ y2 ≤ M
  • 1 ≤ y3 ≤ y4 ≤ M
  • 왼쪽 위가 (x1, y1)이고 오른쪽 아래가 (x2, y2)인 직사각형과 왼쪽 위가 (x3, y3)이고 오른쪽 아래가 (x4, y4)인 직사각형이 차지하는 영역은 서로 겹치지 않는다.
  • 메리가 먹을 수 있는 간식이 없는 경우는 주어지지 않는다.
