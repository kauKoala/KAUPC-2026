KAUPC2026 · A

현수막 출력하기

시간 제한
1초
메모리 제한
512 MB

문제

KAUPC 2026 개막식을 위해 운영진이 다음과 같은 현수막을 준비했다.

KKAAUUPPCC
KKAAUUPPCC
KKAAUUPPCC

현수막은 왼쪽부터 K, A, U, P, C가 적힌 다섯 부분으로 나뉜다. 각 부분은 가로 2칸, 세로 3칸이다.

개막식 직전, 바람이 불어 현수막이 흔들리기 시작했다. 각 부분은 가로 위치와 모양을 유지한 채 높이가 달라진다. 높이 0은 원래 위치, 1은 원래 위치보다 한 칸 위, -1은 한 칸 아래를 뜻한다.

운영진이 전광판에 띄울 현수막의 모습을 5행 10열에 출력하여라. 높이 0인 부분은 위에서부터 2~4행에 놓이며, 문자가 없는 칸은 마침표(.)로 채운다.

입력

첫째 줄에 각 부분의 높이를 나타내는 다섯 정수 h1, h2, h3, h4, h5가 공백으로 구분되어 주어진다. 왼쪽부터 K, A, U, P, C 부분에 해당한다.

출력

흔들린 현수막을 정확히 5줄에 걸쳐 출력한다. 각 줄은 문자와 마침표(.)로 이루어진 정확히 10글자다.

제한

  • h1 = 0
  • -1 ≤ hi ≤ 1 (1 ≤ i ≤ 5)
  • |hi − hi+1| ≤ 1 (1 ≤ i < 5)

예제

예제 입력 1
0 1 0 -1 0
예제 출력 1
..AA......
KKAAUU..CC
KKAAUUPPCC
KK..UUPPCC
......PP..
예제 입력 2
0 1 1 1 0
예제 출력 2
..AAUUPP..
KKAAUUPPCC
KKAAUUPPCC
KK......CC
..........

예제 1 설명

A 부분의 높이는 1, P 부분의 높이는 -1이며 나머지는 0이다.
