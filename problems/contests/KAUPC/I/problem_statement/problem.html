문제

정점 N개와 M개의 양방향 가중치 간선으로 이루어진 그래프가 주어진다.

이후 다음 두 종류의 쿼리를 순서대로 처리하는 프로그램을 작성하시오.

1 a b c: 정점 a와 정점 b를 잇는 가중치 c의 양방향 간선을 하나 추가한다.

2 a b: 정점 a에서 정점 b까지의 최단 거리를 출력한다.

두 정점 사이에 간선이 여러 개 있을 수 있다.

입력

첫째 줄에 정점의 수 N, 초기 간선의 수 M, 쿼리의 수 Q가 주어진다.

다음 M개의 줄에 세 정수 a, b, c가 주어진다. 이는 정점 a와 정점 b를 잇는 가중치 c의 양방향 간선을 의미한다.

다음 Q개의 줄에 쿼리가 한 줄에 하나씩 주어진다.

출력

2번 쿼리마다 최단 거리를 한 줄에 하나씩 출력한다. 경로가 존재하지 않으면 -1을 출력한다.

제한

  • 1 ≤ N ≤ 300
  • 0 ≤ M ≤ 50,000, M < N2
  • 1 ≤ Q ≤ 1,000
  • 1 ≤ c ≤ 100,000
  • 모든 정점 번호 a, b는 1 ≤ a, b ≤ N을 만족한다.
