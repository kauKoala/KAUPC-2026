KAUPC2026 · D

특종은 안전하게

시간 제한
2초
메모리 제한
512 MB

문제

마피아 게임은 시민과 마피아 진영으로 나뉘며, 시민은 마피아를 전부 찾으면 이긴다. 마하가 참가한 마피아 게임의 규칙은 다음과 같다.

1. 매 턴마다 플레이어 중 일부가 참여하며, 마하는 모든 턴에 참여한다.

2. M턴이 지난 후, 마피아는 죽일 상대를 지목하고 시민은 마피아로 추측되는 사람을 지목한다.

3. 시민 중에는 기자가 1명 있다.

4. 기자는 매 턴 마다 특종 스킬을 1번 사용할 수 있다. 스킬을 사용하면 자신과 다른 플레이어 한 명의 정체가 그 턴에 참여한 모든 플레이어에게 밝혀진다.

5. 마피아는 같은 턴에 참여한 시민들을 세뇌 시킨다.

6. 세뇌된 시민과 같은 턴에 참여한 시민도 세뇌 상태가 된다.

7. 세뇌된 시민은 시간과 장소에 구애받지 않고 마피아에게 정보를 전달한다. 즉, 세뇌되기 전에 알게 된 정보도 세뇌된 이후 마피아에게 전달된다.

마하는 마피아 진영에 배정되길 간절히 바랐지만, 기자 직업을 배정받았다.

기자는 마피아에게 매우 위험하기 때문에, 마피아에게 정체가 노출되면 반드시 죽는다.

불쌍한 마하가 살아남아 승리할 수 있도록, 게임 진행자는 마하에게 마피아 명단과 총 M턴 참가자 명단을 몰래 건네주었다.

이제 마하는 마피아 혹은 세뇌될 가능성이 있는 시민이 단 한 명이라도 참여한 턴에서는 특종 스킬을 쓰지 않고, 그 외의 안전한 턴에서는 특종 스킬을 사용해서 시민들의 추리를 도우면 된다!

그런데 이런... 명단에 적힌 턴의 순서가 뒤섞여 있어 실제로 어떤 순서로 진행될지 알 수 없다!

결국 마하는 턴이 어떤 순서로 진행되더라도 마피아에게 정체가 노출될 위험이 없는 안전한 턴에서만 특종 스킬을 사용하려고 한다.

M턴 동안 마하가 특종 스킬을 안전하게 사용할 수 있는 최대 횟수를 구하시오.

입력

첫째 줄에 플레이어 수 N과 턴 수 M이 주어진다.

둘째 줄에 마피아 수 K가 주어진다.

셋째 줄에 마피아 K명의 번호가 공백으로 구분되어 주어진다. 마피아가 0명일 경우 0이 주어진다.

넷째 줄 부터 2*M개의 줄에 걸쳐 턴별 참가자 명단이 주어진다. 명단은 두 줄이 한 쌍이며, i번째 쌍(1 ≤ i ≤ M)에 대해

- 2i+2번째 줄에 그 턴에 참여한 플레이어 수 P가 주어진다.

- 2i+3번째 줄에 그 턴에 참여한 플레이어 P명의 번호가 공백으로 구분되어 주어진다.

여기서 i는 입력에 적힌 위치일 뿐이며, 실제 게임에서 진행되는 턴의 순서와는 관계가 없다.

출력

첫째 줄에 특종 스킬을 안전하게 사용할 수 있는 최대 횟수를 출력한다.

제한

  • 2 ≤ N ≤ 100
  • 1 ≤ M ≤ 50
  • 0 ≤ K < N
  • 1 ≤ P ≤ N
  • 마하는 세뇌되지 않으며, 마하를 통해 세뇌가 전파되지도 않는다.
  • 플레이어 번호는 1부터 N까지이며, 마하는 N명에 포함되지 않는다.
  • 한 턴에 같은 번호는 두 번 이상 주어지지 않는다.
